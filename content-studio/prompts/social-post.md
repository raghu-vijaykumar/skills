# Social Post — Content Studio Prompt

Create a publication-ready social post from `<idea-or-source>` using available Content Studio skills. Choose a single image, animated GIF, carousel of images, carousel with GIFs, or text-led post based on what explains the idea best. Ask for a target platform if unspecified; otherwise use the supplied platform.

## Settings
- Idea / input: `<idea-or-source>`
- Platform: LinkedIn (change to Instagram, X, etc.)
- Audience: Software engineers / curious learners
- Tone: Clear, useful, engaging, technically accurate
- Format: AUTO (single image / GIF / image carousel / GIF carousel / text)
- Carousel length: 4–8 slides when relevant
- Brand: Consistent Revise Labs style when appropriate

## Rules
- Treat YES/NO as explicit switches; do not create formats marked NO.
- For AUTO format, recommend the best format and justify briefly before production.
- Prefer one strong visual concept per slide; use meaningful diagrams and animations, not generic boxes or walls of text.
- A carousel should have a coherent story: hook → explanation → example → takeaway.
- GIFs must loop smoothly, be legible on mobile, and convey one clear motion or mechanism.
- Avoid unsupported claims, fabricated statistics, plagiarism, watermarks, and misleading imagery.
- Adapt dimensions and caption length to the selected platform.
- Preserve editable sources and export platform-ready PNG/JPG/GIF plus caption, alt text, and posting notes.
- Provide a contact sheet and individual previews for approval before final export; never auto-publish without approval.
- Report unavailable skills rather than silently skipping.

## Workflow
Understand Idea → Research → Choose Format → Hook & Outline → Visual Concepts → Generate Assets → Preview → Review → Final Export → Caption & Metadata.
