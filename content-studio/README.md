# Content Studio bundle

`skills/` contains eight installed entrypoints, each owning its own tooling. `skills/content-studio-videogen/` holds the reusable Remotion runtime and CLI. `skills/content-studio-videoedit/` holds the shared channel helper for backup, Drive sync, analytics, vlog ordering, preprocessing, and editing. `skills/content-studio-styles/hairline-source/` preserves upstream attribution and design material. `scripts/` provides installation, local transcription, and a common publication package gate.

Edit this folder in the skills repository, release one tag, then install that exact version in content projects. Do not edit global installed copies.
