# Content Studio bundle

[Content Studio Social](skills/content-studio-social/SKILL.md) organizes YouTube, LinkedIn and Instagram publishing and analytics. Its platform leaves are independently callable and route to the existing implementations. Personal LinkedIn opinions use [LinkedIn Author](skills/content-studio-social/linkedin/author/SKILL.md); its file-backed draft can resume in another chat, and the `content-studio linkedin` CLI enforces angle, draft, final package and publication gates for text, image, animated GIF, document carousel or video. Project presets and per-post production methods keep visual choices flexible.

The [video skill tree](skills/content-studio-video/SKILL.md) holds the working video sources and independently callable operation skills. [The folder map](PROPOSED_FOLDER_STRUCTURE.md) gives the full layout and method status. Only canonical skill entrypoints are exposed; backend scripts remain available where existing commands use them.

## Stage routes

1. Run the [workflow precheck](skills/content-studio-workflow/SKILL.md) before a production edit, including a direct leaf call. Review an editable plan with exact method, script command and arguments, inputs, outputs, estimate, fallback, and acceptance criterion. Approval binds to the plan bytes; record checklist evidence.
2. For a raw camera folder, [prepare individual clips](skills/content-studio-video/source/preprocess/SKILL.md) for the user's manual edit. Diagnose before correcting, preserve originals and Dolby Vision, and flag blur for review. Stop after the clip handoff.
3. When the user supplies a rendered edit, [inspect it](skills/content-studio-video/review/understand/SKILL.md). On request, draft an evidence-linked script, sample the exact picture at the start/middle/end of **each** cue, set visual start/end bounds, and review scene meaning. Shorten lines whose natural-speed audio exceeds those bounds; the default narration assembler rejects scene spill instead of speeding up speech. Obtain text/timing approval, then [mix voice](skills/content-studio-video/audio/narration/SKILL.md), compare and [upscale the completed edit](skills/content-studio-video/edit/upscale/SKILL.md) when justified, and add [scene overlays](skills/content-studio-video/edit/motion-graphics/SKILL.md) at delivery resolution. Select reusable authored CTAs, clips, GIFs, stickers, and Earshot effects from the [stock library](skills/content-studio-video/stock-library/README.md). The [SFX workflow](skills/content-studio-video/audio/sfx/SKILL.md) proposes reviewed placements from picture evidence and authored scene events. [Reel SFX](skills/content-studio-video/audio/reel-sfx/SKILL.md) can create local sound-effect references under that skill's Git-ignored SFX folder; unknown rights or unreviewed audio are excluded from reuse.
4. [Review the exact master](skills/content-studio-video/review/final-render/SKILL.md) and package. Choose [Social's platform publishing skill](skills/content-studio-social/SKILL.md) only after a separate explicit request; [archive](skills/content-studio-video/delivery/archive/SKILL.md) runs independently.

## Original motion explainers

An agent can start with an idea and no channel analytics, then author a [Core Explainer scene plan](skills/content-studio-video/animation/videogen/references/idea-to-explainer.md) inside a videogen project. `plan.py --project-root` creates the neutral brief; `videogen scaffold --style core-explainer` creates the frame and asset contracts; `videogen check` validates them before rendering. The scene runtime provides reusable motion representations for portrait and landscape teaching beats. `videogen narration` and `videogen align-narration` generate original speech and lock one cue per scene. The agent still researches claims, authors specific visuals, inspects hero/detail previews, and reviews the exact full render. Reference footage and audio remain research-only.

[AutoCut](skills/content-studio-video/edit/autocut/SKILL.md) is experimental and explicit-request-only. [Fast pan cuts](skills/content-studio-video/edit/fastpan-cuts/SKILL.md) proposes rapid sweep ranges and reviews synchronized picture/audio removal before a timeline handoff. [Tilt cuts](skills/content-studio-video/edit/tilt-cuts/SKILL.md) shortlists sustained camera-roll candidates for frame review and approved picture/audio removal. [Reflection diagnosis](skills/content-studio-video/edit/reflection/SKILL.md) fixes only minor glare/veil and keeps content-rich reflections REVIEW/UNSUPPORTED; its optional DSRNet `ai` pass attenuates a predicted reflection layer as review-only evidence and never reconstructs occluded content. [Voice cloning](skills/content-studio-video/audio/voice-cloning/SKILL.md) requires consent and listening review. [Styles](skills/content-studio-video/planning/styles/SKILL.md) and [animation](skills/content-studio-video/animation/SKILL.md) support code-driven video, carousel, and posts. [Memory](skills/content-studio-video/memory/SKILL.md) persists only confirmed preferences in a private local SQLite database shared across chats; its absence is shown in the plan.

Copy the [vlog](prompts/full-vlog.md), [animated video](prompts/animated-video.md), or [social post](prompts/social-post.md) form into your Content Studio chat. Fill the inputs and choose which operations to run. The numbered workflow shows the order, parallel steps, and what to review before continuing. Keep drafts, source media, generated audio, model weights, analytics, and secrets outside this bundle.
