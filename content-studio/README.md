# Content Studio bundle

`skills/` contains twelve installed entrypoints, each owning its own tooling. `skills/content-studio-videogen/` holds the reusable Remotion runtime and CLI. `skills/content-studio-videoedit/` holds the shared channel helper for backup, Drive sync, analytics, vlog ordering, per-clip audio tuning, preprocessing, selective AI restoration and upscaling, editing, and quality analysis. `skills/content-studio-audio/` masters audio in a folder of videos. `skills/content-studio-autocut/` builds a reviewable rough cut from raw footage. `skills/content-studio-music/` chooses and records background music. `skills/content-studio-benchmark/` builds synchronized enhancement comparison grids. `skills/content-studio-styles/hairline-source/` preserves upstream attribution and design material. `scripts/` provides installation, local transcription, the music library helper, and a common publication package gate. `assets/music/` holds the local-only YouTube Audio Library and Pixabay catalog; see [assets/music/README.md](assets/music/README.md).

Edit this folder in the skills repository, release one tag, then install that exact version in content projects. Do not edit global installed copies.
