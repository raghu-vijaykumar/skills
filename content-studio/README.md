# Content Studio bundle

`skills/` contains eight installed entrypoints. `toolkit/videogen/` is the reusable Remotion runtime and CLI; `toolkit/content-helper/` owns channel backup, Drive sync, analytics, vlog ordering, preprocessing, and editing. `styles/hairline-source/` preserves upstream attribution and design material. `scripts/` provides installation, local transcription, and a common publication package gate.

Edit this folder in the skills repository, release one tag, then install that exact version in content projects. Do not edit global installed copies.
