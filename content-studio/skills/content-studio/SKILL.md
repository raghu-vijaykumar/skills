# Content Studio

Choose the channel and one draft folder. Read that channel's owner rules and current draft before changing it. For new ideas use `content-studio-ideas`; for Remotion video use `content-studio-animate`; for provided camera clips and a manual edit use `content-studio-vlog`. Route a reviewed final export to `content-studio-publish`. Use `content-studio-archive` for an independent backup and Drive sync. Each specialist owns its checks; do not skip human review.

An idea is a brief, a reviewed render or export is a publication candidate, and a public YouTube backup is a separate archival state. Keep channel data and media in its content repository, not in this skill bundle. A monthly archive run is user initiated.
