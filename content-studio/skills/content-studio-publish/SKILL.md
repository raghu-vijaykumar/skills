# content-studio-publish

Use [Content Studio Social](../content-studio-social/SKILL.md) to choose YouTube, LinkedIn or Instagram publishing. The existing [video publisher](../content-studio-video/delivery/publish/SKILL.md) remains the YouTube/Instagram implementation; LinkedIn uses its separate approved-package CLI. Start with the mandatory content-studio-workflow precheck before production editing and preserve each platform's separate publication authorization. This entrypoint preserves existing skill discovery.
