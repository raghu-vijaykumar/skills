# Content Studio LinkedIn

Use this skill for an idea, opinion, source link, notes or owned asset intended for the user's personal LinkedIn profile. Drafts persist outside chat in the separate personal workspace. Any chat can run `content-studio linkedin list` to find a draft, then `content-studio linkedin resume --draft <id>` and continue from the reported checkpoint. Read [the draft contract and commands](references/workflow.md) when starting or resuming a draft.

Before production, complete the mandatory [Content Studio precheck](../content-studio-workflow/SKILL.md). `linkedin new` initializes a social plan; edit its methods, exact command argv, inputs, outputs, time estimates, fallbacks and review criteria, then show the current revision to the user. `linkedin approve --stage angle` is only for recording the user's explicit approval of that plan, stance, audience, format, brand and narrated or silent choice. A changed plan needs fresh approval.

The agent handles research, writing and media authoring between the durable CLI gates. Preserve the user's stance and first-person voice. Separate opinions from factual claims in `sources.json`; verify facts against primary sources where practical and never invent a personal anecdote, quote, result or statistic. Recommend text, one image, an animated GIF, an information carousel, or a 45–90 second video with a specific reason. Default to English and any professional topic. Choose a personal, Revise Labs or reusable project preset per idea. The production method can change for every post; the final media filename and approval contract stay stable. For an original illustration, record the method and avoid presenting it as source evidence. For an evidence image, record origin and rights.

Review `post.md` and `creative.json` with the user before `approve --stage draft`. For video, review the script and storyboard, choose a representation for every teaching beat, preview hero elements alone, then verify them in the narrated or silent video. Use the existing [code-driven video](../content-studio-video/animation/videogen/SKILL.md) and [content output](../content-studio-video/animation/videogen/content-output/SKILL.md) routes when they fit the approved method. `linkedin render-image` reuses the bundled ContentCard renderer for a branded image; another approved tool may also produce `image.png`. A GIF can be generated by any approved method into `animation.gif`; inspect the complete motion. For an information carousel, review every slide and the assembled `carousel.pdf`; `linkedin build-carousel` optionally assembles numbered 1080×1350 slide PNGs. Confirm mobile safe areas, alt text, rights and full 45–90 second video playback. Narrated video needs audio and `captions.srt`.

Show the exact final copy and media before `approve --stage final`. `linkedin publish` records and shows a network-free dry run with exact copy and hashes. A matching dry run is required before confirmation. Only after a separate explicit request for that exact post may the agent call `linkedin publish --confirm --authorization-note "..."`. Do not auto-approve or infer publication permission from production approval. If the API response is uncertain, stop and reconcile the profile before another attempt. LinkedIn credentials stay in the workspace's ignored `secrets/` folder.
