# Hairline video style

Use `@raghu-vijaykumar/videogen/runtime/hairline` for a frame-seekable isometric line figure. A figure declares an object and a numeric state; the Remotion frame drives all state changes. Use single-weight strokes, rounded geometry, clear silhouette, and sparse highlights. Compose one teaching mechanism per figure, with captions and narration outside the figure. Inspect frames at the resting state, an intermediate state, and the answer state; also inspect a short motion range. The style may be combined with a channel theme without adopting that channel's entire visual identity.

This style is inspired by Lucas Marques's Hairline project. Preserve the MIT attribution in `content-studio/skills/content-studio-styles/hairline-source/LICENSE` when copying source or examples. The original interactive HTML skill is historical reference only.
