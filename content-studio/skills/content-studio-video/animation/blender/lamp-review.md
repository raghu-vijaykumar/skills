# Desk lamp craft benchmark

The original [desk lamp builder](examples/lamp.py) and [version 2 shot specification](examples/lamp.json) demonstrate one measured tabletop prop through the existing headless `blender-shot` method. The same moving artifact supports `blender-modeler` and `prop-artist`: the first route is verified by scene structure and non-destructive geometry; the second by readable scale, separate functional parts, an adjustable pivot, and the visible task-light action. This is an authored example, not a generic modeler for arbitrary prompts.

Blender 5.3 produced an editable `.blend`, hashed PNG frame cache, report, and 96-frame MP4 at 1280×720 and 24 fps. The exact MP4 SHA-256 is `d26318525066927df172965c54e7170839b4e0d36b1a2b3211a3e415ef3a8bd3` and runs 4.000 seconds. The selected [480×270 GIF](previews/lamp.gif) decodes to 32 frames and has SHA-256 `e68eddaada33c03e1f42f7707bcf6a258ac2e3b8d9d39908214a5aa637c1c8d9`. Both routes score this sole full-render candidate **82/100** in [scores.json](scores.json), so each selection is provisional until a competing candidate is scored.

The exact encoded frames at 0.25, 2.0, and 3.75 seconds were inspected. The initial head is raised and the notebook is unlit; during the action the head lowers and a warm pool appears; the final pose holds with the base, shade, and notebook inside frame. The pool is prominent in the MP4 and smaller but still visible in the GIF. The notebook is a simple context object, and the hinge, cable, and electrical details are illustrative.

The saved `.blend` passed [structural audit](scripts/audit_lamp.py): metric scale 1.0, preserved hidden `COL_Blockout`, separate `COL_Geo`, thirteen named manifold mesh parts, 4,184 source triangles, applied mesh scales, a 0.36 m base diameter, four upper-assembly children on the animated head pivot, and live bevel modifiers on the base and shade. The audit report is in the ignored render workspace. UV layout, textured wear, export, and engine reimport are separate catalog routes and are not claimed by this benchmark.

Rebuild from the repository root using the [gallery command pattern](README.md#rebuild-the-showcases) with `lamp.py`, `lamp.json`, `common.py`, and `tmp/lamp-v2.mp4 --resumable --batch-frames 24`. Run `blender --background --factory-startup --python-exit-code 1 --python content-studio/skills/content-studio-video/animation/blender/scripts/audit_lamp.py -- --blend tmp/lamp-v2.blend --out tmp/lamp-v2-structural.json` against the saved scene. Keep large MP4, `.blend`, cache, and private source assets outside Git.
