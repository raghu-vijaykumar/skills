# Full Blender roadmap audit

The machine-readable [94-row audit](roadmap-audit.json) is generated by `python scripts/audit_roadmap.py --output roadmap-audit.json`. The script validates the pinned catalog, score rubric and winner selection, Blender README table and inline embeds, selected GIF hashes, and every GIF's final frame decode. Run it after changing the manifest, scorebook, or showcase.

| Gate | Verified result |
| --- | --- |
| Catalog | 94 unique pinned routes: 90 Rendered, 3 Prototype, 1 Catalogued, 0 Integrated. |
| Scoring | 137 candidate score records across 69 score routes; each record has five editorial scores, a technical verdict, dimensions, frame count, video/GIF hashes, reviewer, date, and reason. Every selected route is the highest-scoring eligible candidate. |
| README media | 67 distinct winning GIF files decoded through their final frame and appear inline above the 94-row table. The 31 core/extended/horror styles and all 55 visual routes use distinct GIFs. Craft routes may share a scored shot when their review explains the demonstrated skill. |
| Asset handoff | Generic, Unity, and Godot GLB plus Unreal FBX each passed 26/26 Blender reimport checks for hierarchy, topology, dimensions, UVs, materials, animated turn, and collision proxy. See the [export review](game-asset-review.md). Actual engine editor imports are pending. |
| Planner | `blender-director` has a [planning method and guide](director.md); it remains Catalogued because it produces a proposal, not media. |

The scorebook preserves hashes and decisions for rejected candidates while full MP4s, `.blend` scenes, and render caches stay outside Git. This audit verifies current committed GIF files and recorded scores; it does not rerender all 137 historical candidates or prove that every older ignored MP4 is still on this machine. Each rendered row is a **bounded example** documented in its linked review, not a general renderer for every subject and style combination. The three named game engine exports remain prototypes until editor tests are performed.
