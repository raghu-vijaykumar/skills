# Blender shot direction in Content Studio

`blender-director` is integrated as planning guidance in the existing video animation route. It proposes a shot; it does not create a scene or earn a showcase GIF. Its upstream [director instructions](https://github.com/arjun988/blender-skills/blob/904f095d8f36a6e72adaebb08d07f884a074743d/.claude/skills/blender-director/SKILL.md) inform this route, while Content Studio's workflow approval and review gates control production work.

1. Read the brief, channel, source references, narration or teaching beat, delivery format, rights, and intended hero action. Identify which appearance or mechanism must read at the final frame size. For a production draft, complete the [mandatory workflow precheck](../../../content-studio-workflow/SKILL.md) before editing.
2. Run `python content-studio/skills/content-studio-video/animation/blender/scripts/catalog.py plan "<brief>"` with optional `--subject`, `--style`, `--world`, `--genre`, `--era`, and `--capability` overrides. Preserve explicit user choices. The response identifies a demonstrated builder only when subject, treatment, and intent match its narrow example; otherwise `Catalogued` means a new builder is needed.
3. Put the proposed subject, dominant style, optional world/mood/genre/era, object hierarchy, animation action, camera, lighting, simulation or VFX, budget, output size, and three review frames into the editable production plan. The [94-entry catalog](capabilities.json) gives dependencies; the linked review and [score records](scores.json) show what each example actually proves. For a new scene, use the [version 2 shot contract](shot-contract.md) and record original or approved asset rights.
4. Name the exact preview and full-shot commands, estimated time, output files, fallback, and acceptance criteria in the workflow plan. For a demonstrated builder, use the command pattern in the [gallery README](README.md#rebuild-the-showcases). Preview the hero alone, then the first/action/result frames, then the complete shot at delivery size. Score **every** full render candidate on the five rubric dimensions; select only the best technically valid GIF for the Blender README.
5. Review the shot at its narrated cue using the [hashed videogen handoff](README.md#reviewed-videogen-handoff). Any production edit needs explicit approval of the current workflow plan. A Blender-only round trip does not prove a Unity, Unreal, or Godot editor import.

When a request omits a style, use the brief's visual and channel cues to propose one. Examples: a measured clamp defaults to the demonstrated realistic lane, a cel heroine to anime, and a horror corridor to psychological horror only when its subject and beat match the reviewed examples. An explicit unsupported combination remains a request for a new builder and must not inherit an unrelated GIF.
