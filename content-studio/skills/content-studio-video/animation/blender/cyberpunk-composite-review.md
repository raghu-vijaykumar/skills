# Cyberpunk beauty compositing review

The original [compositor builder](examples/cyberpunk_composite.py) wraps the existing authored [cyberpunk alley](examples/cyberpunk_alley.py) with an editable Blender 5 beauty graph. Both candidates use the same geometry, lighting, camera, and courier action. V1 links Combined straight to Group Output. V2 adds −0.10 exposure, 1.06 saturation, and fog glow with threshold 0.70, strength 1.0, and size 0.85. The scene retains AgX and enables a Mist pass for later isolation, but the current graph uses only Combined. Blender 5's [compositor migration](https://developer.blender.org/docs/release_notes/5.0/migration/compositor_migration/) replaces the old Composite node with a Group Output color socket. The [pinned upstream compositing guidance](https://github.com/arjun988/blender-skills/blob/904f095d8f36a6e72adaebb08d07f884a074743d/.claude/skills/compositing/SKILL.md) informed the reversible grade and glare chain.

Both complete Blender 5.3 candidates passed the 72-frame, 960×540, 24 fps shot contract. Their encoded first, courier-crossing, and final frames were inspected; both 480×270 GIFs decode to 24 frames. The selected GIF's sampled frames retain the drone and show soft neon halos without losing the street silhouette. The exact encoded frame 48 differs from the raw control by mean absolute RGB **11.73, 9.59, 10.59** on the 0–255 scale. The [scorebook](scores.json) records **raw v1 68/100** (subject 3, motion 3, composition 4, finish 3, evidence 5) and **selected v2 77/100** (4, 3, 4, 4, 5). These are editorial judgments, not audience metrics.

The [saved-scene auditor](scripts/audit_cyberpunk_composite.py) verifies AgX, enabled compositing, a Blender 5 `CompositorNodeTree`, the raw and treated link chains, exact exposure/saturation/glow values, unchanged underlying cyberpunk action, and delivery geometry. This demonstrates a bounded beauty treatment. It does not claim cryptomatte isolation, multilayer EXR archival, pass recombination, color matching to external footage, or a generic compositing preset. The chosen glow is intentionally visible for the showcase and should be tuned against a real production shot.

To rebuild from this directory, run `scripts/render_shot.py` with `--builder examples/cyberpunk_composite.py --input examples/cyberpunk_composite.json --dependency examples/common.py --dependency examples/cyberpunk_alley.py --out tmp/composite-v2.mp4 --resumable --batch-frames 72` under Blender 5.3. For v1, copy the JSON to ignored `tmp/composite-v1.json`, change `variant` to `1`, and render to a distinct output. Audit each saved `.blend` using `blender --background --python scripts/audit_cyberpunk_composite.py -- --blend <saved.blend> --out <report.json>`. The [best GIF](previews/cyberpunk-composite.gif) is embedded inline in the Blender README; rejected full media remain ignored in `tmp/`.
