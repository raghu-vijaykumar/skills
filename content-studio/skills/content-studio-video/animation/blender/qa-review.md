# Screenshot-backed Blender QA lane

The [pinned upstream QA guide](https://github.com/arjun988/blender-skills/blob/904f095d8f36a6e72adaebb08d07f884a074743d/.claude/skills/qa-review/SKILL.md) calls for inspected angles, a budget, severity, and an explicit verdict. Content Studio's [QA script](scripts/qa_review.py) opens an authored `.blend`, isolates a named mesh for three-quarter and profile captures, checks topology and triangle budget, verifies the exact MP4 and selected GIF hashes and video dimensions, and requires a visual verdict and note before it can report `SHIP`. Without visual review it reports `REVIEW`; failed technical checks or a major defect report `NO-SHIP`. It leaves the saved scene unchanged. This is a local Blender QA lane, not an automated sign-off of all 94 routes.
