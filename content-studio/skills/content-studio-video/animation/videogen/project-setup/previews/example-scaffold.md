# Project setup example

Illustrative command/output example. Both scripts forward to the maintained videogen
CLI; they do not create a new renderer.

```powershell
node content-studio/skills/content-studio-video/animation/videogen/project-setup/scripts/init.mjs my-project
node content-studio/skills/content-studio-video/animation/videogen/project-setup/scripts/scaffold.mjs <draft>
```

`init` is one-time for a new project. `scaffold` adds the editable draft structure and
preserves existing authored scenes. Review the chosen theme and format before authoring.
