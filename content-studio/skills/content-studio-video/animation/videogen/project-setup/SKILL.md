# content-studio-video-project-setup

Before production edits, complete the mandatory `content-studio-workflow` precheck with the exact method, script, outputs, estimate, and review criterion. Use `scripts/init.mjs` once for a new project and `scripts/scaffold.mjs` for a draft. Both forward to the maintained videogen CLI. Preserve existing authored scenes and review the chosen theme and format.
