# From an idea to an authored Core Explainer

This is an **agent-run** route through the existing Content Studio draft and videogen commands. A scene plan is an executable timing and provenance contract; it is not an automatic story generator. The agent still chooses the explanation, checks sources, authors visual representations, and reviews real frames.

1. Run the `content-studio-workflow` precheck. Record the idea, reference scope, available system capacity, method IDs, commands, outputs, fallbacks, estimates, and review criteria. Follow the approved checklist. Publication has a separate gate.
2. Research primary sources and write a concrete viewer promise. For no channel, run `python planning/ideagen/scripts/plan.py --project-root <project> --name "<idea>" --kind long --promise "<what the viewer will understand>"` (add `--duration S` for a fixed private study). This route has no channel analytics. A configured channel can still use `--channel` and its owned insights.
3. Select `core-explainer` in the built-in style registry and create a draft with `videogen scaffold <id> --title "..." --style core-explainer --duration 300 --width 1920 --height 1080`. The scaffold creates a valid one-scene starter that must be replaced with an authored script and scene plan.
4. Write `scene-plan.json` and `asset-manifest.json` under the draft. Each scene has absolute `[startFrame,endFrame)` at 30 fps; a supported `type`; teaching title and visual; `stateChanges` and `camera` frames; presenter state; narration, source, audio and asset IDs. Scenes cover the full composition without gaps. The render rejects unknown types and unlisted or changed assets. See the scaffold output for the exact schema.
5. Author the narration in `content/narration.yaml`, link it from `content/video.yaml`, then run `videogen narration <id>`. When one phrase belongs to each scene and timing must lock to frames, run `videogen align-narration <id>`; it accelerates only phrases that exceed their scene and pads shorter phrases. Review any phrase requiring more than 1.7× speed. The original generated audio is retained as a private derived cache for re-alignment.
6. For visual design, import `ExplainerFilm` from `@raghu-vijaykumar/videogen/runtime/motionExplainer`. The reusable `hero`, `device`, `flow`, `stack`, `code`, `data`, `document`, and `presenter` representations carry deterministic motion. Supply distinct original cutouts through `presenterImages` for speaking, pointing, and thinking poses when the presenter recurs; a single `presenterImage` remains a still and cannot supply lip sync. Override a scene with an authored component when the generic object does not clearly teach the mechanism. Rendering only a title sequence or generic cards is insufficient. `videogen score <id>` can generate an original, deterministic ambient bed and scene accents from the plan; mix it quietly under voice, then listen to the exact output.
7. Run `videogen check <id>`, then render bounded hero and detail shots with `videogen render <id> --from S --to E`. Inspect frames at native size for readability, depth, continuity, audio sync, and source accuracy. Record actual timecoded evidence. Run `videogen render <id> --delivery` for a requested full output, inspect the exact master and full audio, and measure integrated loudness and true peak. If the approved plan includes audio mastering and the mix misses its acceptance gate, use the existing `content-studio-video-mastering` route. Complete the checklist after final review.

## Provenance boundary

The asset manifest lists every imported or generated media file by project-relative path, SHA-256, origin (`procedural`, `generated`, `recorded`, or `licensed`), and licence or private-use note. The validator checks declared assets and direct static imports from `video.tsx`; it refuses reserved `reference`/`source-reel`/`source-media` directories and escapes outside the draft, including symlink escapes. Audit custom scene modules and dynamic media paths separately. A reference can guide timing and framing in research only; it must not appear in a composition or delivered media. Source IDs identify public facts; mark diagrams of undocumented internals as illustrative.
