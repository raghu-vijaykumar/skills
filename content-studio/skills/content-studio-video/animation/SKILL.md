# content-studio-video-animation

Use [videogen](videogen/SKILL.md) for Remotion projects and [engineering 3D](engineering-3d/SKILL.md) for Blender projects with original procedural or approved imported geometry. Use the [Blender preview tool](engineering-3d/references/headless-preview.md) to verify representative component states and frame cost before scaling up. Choose a visual representation for each teaching beat, preview hero elements alone, then verify in the narrated render. All production edits require the workflow precheck and rendered review.

For 2D, 2.5D, 3D and hybrid work with authored heroes, use the [per-part and per-action review loop](../review/critique/references/object-scoring.md#production-checkpoints) at narrated proof and exact master. Carry the inventory from the storyboard into both reports. Fix gaps with bounded rerenders and rescore the same actions.
