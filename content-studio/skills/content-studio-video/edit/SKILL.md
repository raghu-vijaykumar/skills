# content-studio-video-edit

The default story edit is performed by the user. [AutoCut](autocut/SKILL.md) runs only on explicit request. Use [clip edit](clip-edit/SKILL.md), [transitions](transitions/SKILL.md), [reframe](reframe/SKILL.md), [color](color/SKILL.md), [restoration](restoration/SKILL.md), and [reflection](reflection/SKILL.md) only for diagnosed, approved work. Apply [upscale](upscale/SKILL.md) to the completed manual edit after any voice mix, then add [motion graphics](motion-graphics/SKILL.md) at delivery resolution. Each leaf skill is directly callable after its own approved precheck.
