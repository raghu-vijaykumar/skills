# Synthetic object-blur evidence

Run `python -m unittest discover -s content-studio/skills/content-studio-video/edit/object-blur/tests -p "test_*.py"`. The delivery test creates a 160 × 90, four-frame source with two red objects, one moving. It writes an exact frame mask, enters a human *fixture* review, and renders through the same single-export FFmpeg graph as production. The rendered frame was inspected at native size: the red rectangles became soft, faint shapes while the dark background stayed unchanged. Tests also check target and outside-mask pixels, copied audio packet hashes, stale-hash rejection, and frame coverage. A separate local pilot loaded both pinned real checkpoints and produced a four-frame mask. The fixture approval is not a production approval; source clips, masks, and previews are written to temporary storage.
