# Synthetic object-blur evidence

Run `python -m unittest discover -s content-studio/skills/content-studio-video/edit/object-blur/tests -p "test_*.py"`. The delivery test creates a 160 × 90, four-frame source with two red objects, one moving. It writes an exact frame mask, enters a human *fixture* review, and renders through the same single-export FFmpeg graph as production. The rendered frame was inspected at native size: the red rectangles became soft, faint shapes while the dark background stayed unchanged. Tests also check target and outside-mask pixels, copied audio packet hashes, stale-hash rejection, and frame coverage. A separate local pilot loaded both pinned real checkpoints and produced a four-frame mask. The fixture approval is not a production approval; source clips, masks, and previews are written to temporary storage.

The [README face-only GIF](face-only-blur.gif) uses the [HD Pexels video by Kampus Production](https://www.pexels.com/video/close-up-shot-of-a-man-talking-7514340/) under the [Pexels license](https://www.pexels.com/license/). Source SHA-256: `30c30efe7298b19bfe9ec7aeb9f56e4c4a88ae52dda3a84849d3fb4d0bff9998`. Download the [1920 × 1080, 25 fps file](https://videos.pexels.com/video-files/7514340/7514340-hd_1920_1080_25fps.mp4), then run `python content-studio/skills/content-studio-video/edit/object-blur/previews/build_example.py --source <downloaded-video.mp4>`. The builder selects 0.5–2.5 seconds, downsizes to 640 × 360 at 4 fps, uses hand traced per-frame face polygons as corrections, and renders the pending timeline preview through the native FFmpeg graph. The GIF compares matched source and preview frames. The mask targets the face while clothing and background stay clear. Automated text detection and segmentation are not exercised in this example; every frame remains flagged for coverage review. The source video and temporary masks stay outside Git.
