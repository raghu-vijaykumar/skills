# content-studio-video-color

Before production edits, complete the mandatory `content-studio-workflow` precheck with the selected method, exact script, output, estimate, fallback, and review criterion. Use `scripts/preset.py` for a selected existing look and `scripts/shot_match.py` for a reference-matched correction. Compare the untouched edit, check temporal consistency, and review affected ranges. A standalone LUT method is not yet a supported script.
