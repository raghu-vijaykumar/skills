# Meme insertion proposal example

Illustrative proposal only; it does not modify a timeline.

```json
{
  "meme_id": "synthetic-reaction-01",
  "at_seconds": 12.5,
  "duration_seconds": 1.2,
  "mode": "cutaway",
  "reason": "Synthetic example grounded in an observed reaction beat",

```

The default maximum is 1-3 per 10 minutes. Human review approves rights and timing
before any editable timeline changes. Automated semantic detection and insertion are
not implemented.
