# content-studio-video-style-core-explainer

Run the mandatory `content-studio-workflow` precheck before production edits. Select the exact supported style, renderer and method scripts in the approved plan. Use the current built-in style registry and shared videogen design tokens. Choose a teaching representation for each beat, keep source evidence attached, and review the rendered scene and final export. Read [Core Explainer guidance](references/core-explainer.md).

For a fast, narrated motion treatment, use the [reconstruction checklist](../../../review/critique/references/reconstruction.md) to design word-timed actions, original hero assets, character poses, camera and sound cues, and exact render comparisons. Apply the same checklist to the new teaching mechanism when adapting the treatment to a different subject.
