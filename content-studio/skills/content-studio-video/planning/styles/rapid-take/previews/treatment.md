# Rapid Take treatment example

The `rapid-take` treatment supports fast, word-timed video. For a timing analogy,
“The clock runs like a pizza timer” could use the following cue plan excerpt.

| Word | Actor | Cue kind | Visible event |
| --- | --- | --- | --- |
| The | Stage | Editorial | Frame the empty pedestal |
| clock | Clock | Object | Drop the clock face into view |
| runs | Clock hand | Object | Start the sweep with a saturated accent |
| like | Clock hand | Continuation | Sweep into a radial wipe |
| a | Countertop | Continuation | Wipe reaches the counter's edge |
| pizza | Pizza | Object | Slide in a pizza with separate slices |
| timer | Dial | Object | Twist the kitchen timer and start its countdown |

Fill in word frames from the actual narration. Source reference views of the
clock, pizza and timer and draw separate moving layers. The same cues work with
cel-shaded or pixel-art layers if the hand and dial keep their pivots.

Review path:

1. Confirm the style is enabled in the selected project and supports the requested format.
2. Attach source evidence to every factual beat.
3. Render the cue sequence, then inspect the object at and around each onset.
4. Score the actors in the exact render and retest deficits. Follow the workflow precheck for production edits.

No renderer is claimed by this planning skill. Unsupported formats must stop before export.
