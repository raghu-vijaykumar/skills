# Music selection record example

Illustrative record; no catalog reference or audio is committed.

```json
{
  "title": "Synthetic Track (illustrative)",
  "category": "cinematic",
  "license": "youtube-audio-library",
  "attribution": "No attribution required.",
  "note": "Illustrative shape only; not a real selection or licence record."
}
```

Sources must be downloaded manually from YouTube Audio Library or Pixabay. Never scrape
or automate either site, never commit MP3s, and check the Pixabay Content ID shield.
