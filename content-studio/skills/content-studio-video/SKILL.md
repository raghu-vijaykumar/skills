# content-studio-video

A raw video folder defaults to [source preprocessing](source/preprocess/SKILL.md) and a stop for manual editing. A supplied manual render can enter [understanding](review/understand/SKILL.md), [narration](audio/narration/SKILL.md), [reflection diagnosis](edit/reflection/SKILL.md), [full-edit upscale](edit/upscale/SKILL.md), [transitions](edit/transitions/SKILL.md), then [motion graphics](edit/motion-graphics/SKILL.md), only when those stages are requested. Code-driven work routes to [animation](animation/SKILL.md). [AutoCut](edit/autocut/SKILL.md) is experimental and explicit-request-only.

Before production editing, run the top-level [workflow precheck](../content-studio-workflow/SKILL.md) and obtain approval of the current plan, including exact operation, method script, output, estimate, fallback, and review criterion. Every child skill can be invoked directly and must follow that gate. Preserve originals and verify the exact output.
