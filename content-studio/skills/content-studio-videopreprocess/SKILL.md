# Content Studio Video Preprocess

Read the channel rules and the draft's original camera clips in `original/`. On the first run, legacy files at the draft root are migrated automatically: raw clips move into `original/`, `processed-clips/` moves under `.content-studio/`, `video.mp4` becomes `<id>-final.mp4`, `video/` and `rough-cut/` move under `.content-studio/`, `audio-mastered/` becomes `.content-studio/audio/`. Preview mixed-device capture order with `python <bundle>/skills/content-studio-videoedit/scripts/content.py order --channel <slug> --draft <id> --dry-run`. Run `order` to record `.content-studio/_timeline.csv` and number `original/` camera files by capture time; supply `--utc-offset` when the location offset cannot be inferred. Existing timeline timestamps remain fixed when new clips arrive.

Run `python <bundle>/skills/content-studio-videoedit/scripts/content.py preprocess --channel <slug> --draft <id>`. For a standalone folder outside a channel workspace, run `preprocess --folder <path> --utc-offset <offset>`; it adopts the same layout, deduplicates, orders, renumbers, and writes `.content-studio/processed-clips/`. Add `--final` to render a publish-ready SDR `final.mp4` per clip at the highest source resolution, with the enhanced voice baked in, every detected blur span removed, and two-pass `vidstab` stabilization applied by default; folder and draft runs join those clips into `<id>-preprocessed.mp4`. Mixed resolutions use the largest canvas and upscale smaller clips, never downscale the largest. Use `--size auto|WxH` to override; fps is normalized to 30. Mismatched clips default to a blurred copy of themselves behind the centered clip; use `--fit pad` for black pillars or `--fit crop` to fill. The final path drops Dolby Vision RPU, so keep the `--dv-proof`/`--dv-approved` flow when DV must be preserved. Preprocessing also compares clip contents before numbering: byte-identical copies are moved to `.content-studio/analysis/duplicates/`, while near-duplicate shots are listed in `.content-studio/analysis/duplicates/review.csv` for approval. Set `remove=yes` for a near-duplicate row and rerun preprocess to quarantine it. Inspect blur spans, stabilization crop, audio cleanup, and review reports before applying proposed cuts. Original footage remains available in `original/`. Dolby Vision outputs must preserve RPU and frame alignment; otherwise use the original video with cleaned audio. Read the [preprocessing guide](../content-studio-videoedit/references/channel-helper.md) for the review flags and output paths.

Hand the reviewed clips and `.content-studio/_timeline.csv` to `content-studio-videoedit` for trim, cut, join, or manual assembly. When you want a rough cut, use `content-studio-autocut` first: stage the per-clip `final.mp4` exports in a flat folder such as `.content-studio/autocut-input/`, because AutoCut scans only the folder's top level. Do not treat preprocessing as approval of a final master.
