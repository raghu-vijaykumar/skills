# Content Studio Video Preprocess

Read the channel rules and the draft's original camera clips. Preview mixed-device capture order with `python <bundle>/skills/content-studio-videoedit/scripts/content.py order --channel <slug> --draft <id> --dry-run`. Run `order` to record `_timeline.csv` and number camera files by capture time; supply `--utc-offset` when the location offset cannot be inferred. Existing timeline timestamps remain fixed when new clips arrive.

Run `python <bundle>/skills/content-studio-videoedit/scripts/content.py preprocess --channel <slug> --draft <id>`. For a standalone folder outside a channel workspace, run `preprocess --folder <path> --utc-offset <offset>`; it deduplicates, orders, renumbers, and writes `processed-clips/` inside that folder. Add `--final` to render a 1920x1080 16:9 BT.709 SDR `final.mp4` per clip with the enhanced voice baked in and every detected blur span removed; folder and draft runs join those clips into `final-video.mp4`. Mismatched clips default to a blurred copy of themselves behind the centered clip; use `--fit pad` for black pillars or `--fit crop` to fill. The final path drops Dolby Vision RPU, so keep the `--dv-proof`/`--dv-approved` flow when DV must be preserved. Preprocessing also compares clip contents before numbering: byte-identical copies are moved to `draft/analysis/duplicates/`, while near-duplicate shots are listed in `draft/analysis/duplicates/review.csv` for approval. Set `remove=yes` for a near-duplicate row and rerun preprocess to quarantine it. Inspect blur spans, stabilization crop, audio cleanup, and review reports before applying proposed cuts. Original footage remains available. Dolby Vision outputs must preserve RPU and frame alignment; otherwise use the original video with cleaned audio. Read the [preprocessing guide](../content-studio-videoedit/references/channel-helper.md) for the review flags and output paths.

Hand the reviewed clips and timeline to `content-studio-videoedit` for trim, cut, join, or manual assembly. When you want a rough cut, use `content-studio-autocut` first: stage the per-clip `final.mp4` exports in a flat folder such as `analysis/autocut-input/`, because AutoCut scans only the folder's top level. Do not treat preprocessing as approval of a final master.
