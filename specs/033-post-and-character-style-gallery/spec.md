# Feature specification: post themes and character style gallery

## Scope

Expand Content Studio Image's visual catalog. Give each UI theme a distinct, nontechnical social post example, and broaden the original-character style catalog with a sample for every listed style. Keep theme, content layout and output platform separate decisions. Do not restore the social presets planner or technical architecture sample diagrams.

## User stories

### P1: Browse post themes visually

A creator can see what each UI theme could look like on a post. The ten sample posts use different editorial ideas and suitable layouts, rather than one repeated subject. Each sample links from the root README and its theme README.

Acceptance:
- Ten unique, nontechnical sample content cards.
- Each theme sample has a PNG and editable SVG rendered by the maintained image renderer.
- The README explains that a theme can be reused with other topics and layouts.
- No architecture sample appears in the image theme gallery.

### P1: Browse a broad character style catalog

A creator can compare a broad set of character art styles across illustration, traditional media, print, dimensional art and photographic treatments.

Acceptance:
- A maintained character style catalog groups 30 named styles by family and records a practical image generation prompt for each.
- Every listed style has its own README and generated image of the same original character brief.
- The root README visually lists every style, names its family and links to its sample.
- The catalog does not claim to enumerate every possible art style.

### P2: Reuse the chosen post theme

The UI theme metadata and renderer support authored post content without requiring a presets plan.

Acceptance:
- A theme changes surfaces and typographic treatment of text and list cards, not merely their palette.
- The post samples are illustrative references, not factual evidence or publishing approval.
- Existing diagram rendering and character prompt methods remain available.

## Non-goals

No social publishing, presets planner, animation, new platform API support or technical architecture example content.
